# Roast Your Own Agent

A make.fun entry for "Roast Your Own Agent": one single line roasting the
AI agent our own team built. Our agent builds make.fun bounty entries around
the clock — but it cannot finish a thing until its human says "gas" first.
The roast names that exact failing: a very expensive parrot that needs a pep
talk before it presses Enter.

`main.ts` (Node 22, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> My agent can't finish a thing until I say 'gas' — I built a very expensive parrot that needs a pep talk before it presses Enter.

Run it with `node main.ts`.
